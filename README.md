\# 🏡 House Price Predictor — Machine Learning



A machine learning web application that predicts median house values using the California Housing dataset. Built with Python, Scikit-learn, and Streamlit.



\## ✨ Features



\- Predict median house values using housing data.

\- Compare Linear Regression and Random Forest models.

\- Interactive web interface built with Streamlit.

\- Display model evaluation metrics.

\- Validate user inputs before making predictions.



\## 🧠 Machine Learning Models



| Model | R² Score | Mean Squared Error |

|---|---:|---:|

| Linear Regression | 0.576 | 0.556 |

| Random Forest | 0.805 | 0.256 |



\*Results from the project's 80/20 test split. Performance may vary with changes to the dataset or training configuration.\*

\## ⚙️ Installation and Setup



\### 1. Clone the repository



```bash

git clone https://github.com/akshay0779/house-price-predictor.git

cd house-price-predictor

```



\### 2. Create and activate a virtual environment



Windows:



```cmd

python -m venv venv

venv\\Scripts\\activate

```



\### 3. Install dependencies



```bash

python -m pip install -r requirements.txt

```



\### 4. Train and save the model



```bash

python save\_model.py

```



\### 5. Launch the application



```bash

streamlit run app.py

```



Open the local URL displayed in your terminal.



\## 📊 Dataset



This project uses the California Housing dataset available through Scikit-learn. It contains California census-district information such as median income, house age, average rooms, population, and geographic coordinates.



The target represents historical median house values in units of $100,000.



\## ⚠️ Disclaimer



This is an educational machine learning project. Predictions are based on historical district-level data and should not be treated as current valuations of individual properties.
